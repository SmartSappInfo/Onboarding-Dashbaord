## 5. Security, Cryptography & Governance Matrix

1. **Rule 4 Zero-`any` Policy:**
   - 100% typed with TypeScript and Zod v4.
   - Zero occurrences of `any` or `any[]` in executable code across all contracts, services, actions, and UI components.
2. **Rule 8 & 47 Multi-Tenant Anti-IDOR Boundary:**
   - Scoped `assertTenantAccess` enforced across every single Server Action in the platform.
   - Cross-tenant requests fail closed immediately with HTTP 403 `IDOR_VIOLATION`.
3. **Rule 13 & 30 Prompt Injection Isolation:**
   - Untrusted model input/output previews and execution proofs wrapped in `<untrusted_reference_data id="..." source="...">` XML containers.
   - Linear non-backtracking scanning against `ADVERSARIAL_DIRECTIVE_PATTERNS`.
4. **Rule 16 & 17 Non-Delegable Authority Engine:**
   - Non-delegable root privilege firewall strictly guarding destructive and administrative mutations (`auth.*`, `platform_config.*`, `toggleEmergencyDeadMan`, `resetCircuitBreaker`).
   - Human-only verification gate (`actor.type === 'user'`).
5. **Rule 21 & 22 Two-Phase Approval Staging & SHA-256 Digest Binding:**
   - Mutating proposals staged with cryptographic SHA-256 hashes over canonical key-sorted JSON (`canonicalizeJson`).
   - Detects out-of-band tampering (`PAYLOAD_TAMPERED`).
6. **Rule 24, 25, 26, 27 Distributed Resilience Core:**
   - Dynamic tri-state circuit breakers (`CLOSED` -> `OPEN` -> `HALF_OPEN`).
   - Automated quarantine to Dead-Letter Queue (DLQ).
   - Cooperative cancellation via native `AbortSignal`.
   - Universal Reverse-LIFO Saga compensation coordinator rolling back multi-domain mutations in reverse order.
7. **Rule 60 & 61 Backoffice Control Plane:**
   - Granular dead-man kill switches failing closed across all actions without code redeployment.
   - Mandatory operator justification notes requiring $\ge 5$ characters with live UI counter.
8. **Rule 62 Real-Time SSE Reactivity:**
   - Reactive UI synchronizations via `useEventStream` subscribing to domain events (`evaluation.*`, `agent.health.*`, `supervisor.*`).
9. **theme.md §8 Standardized Modal SSOT:**
